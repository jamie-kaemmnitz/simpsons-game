Online Quiz based on the Simpsons TV Show
=================================================================
Project description
-------------------
I have created a small quiz based on the Simpsons TV show, the opening screen shows a title and a brief description on how the game works, answering 5 questions in a row to complete the quiz. at the bottom there is a 'start quiz' button which will take onto the first question of the quiz.

The quiz page consists of 5 different questions each with four multiple choice ansers, the user can only select one answer for each question. The questions will show up one at a time in order from one to five, a correct answer is required to move onto the next question, if a wrong answer is given at any point in the quiz then an image will pop up with a 'd'oh' message and the user will have to click the 'try again' button to return to the first question. if a correct answer is given then a 'woohoo' image will appear with a next question button which will take the user to the next question in line. The fifth question is the only one that is based on identifying a character from an image. 

If the fifth question has been answered correctly then the user will again see the 'woohoo' page but once clicking the next question button they will directed to the GIF html page, This will bring up a page with a GIF of homer simpson dancing at the top of the page, with a congratulations message and a button to take you back to the home screen.

The whole page has been designed mainly in skyblue and yellow colours with a Simpson style font added for a more unique Simpsons feel.

The entire webpage was created using HTML CSS and Javascript.

----------------------
You cabn download the code by clicking the green code button and copying the link in the box. You can also run the webpage by entering the following link into your browser - https://jamie-kaemmnitz.github.io/simpsons-game/
